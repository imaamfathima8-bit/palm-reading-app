# Palm Reading App

Palm Reading App is a computer-vision and AI application built with Streamlit. It processes uploaded palm images through a seven-stage OpenCV and MediaPipe pipeline, extracts visual features, and uses a grounded retrieval-augmented generation chatbot to answer user questions.

This project demonstrates skills in image processing, computer vision, Streamlit application development, and retrieval-augmented generation. It is intended as a technical demonstration and entertainment-oriented application, not as a medical, psychological, or predictive tool.

## Key Features

- Palm-image upload through a Streamlit interface
- Seven-stage image-processing pipeline using OpenCV and MediaPipe
- Palm-feature detection and visual processing
- Grounded RAG chatbot for user questions
- Interactive web application built with Streamlit

## Disclaimer

This application is a computer-vision and AI demonstration. It does not provide medical, psychological, financial, or predictive advice. Its outputs should not be used for health, financial, or life decisions.
